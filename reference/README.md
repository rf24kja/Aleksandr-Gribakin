# reference

Материалы для представления сайта: скриншоты, веб-витрина и два PDF.

Всё здесь собирается из работающего сайта, а не рисуется вручную. Если сайт
изменился, материалы пересобираются тремя командами (см. ниже) — расхождение
между презентацией и реальностью исключено по построению.

## Что где лежит

| | |
|---|---|
| `screenshots/` | 12 снимков с `dev24.pro`: три режима, обе темы, десктоп и телефон |
| `showcase.html` | веб-витрина, одна самодостаточная страница (1.1 МБ) |
| `dev24-portfolio-ru.pdf` | справочный документ, 11 страниц A4 |
| `dev24-portfolio-en.pdf` | то же на английском |
| `print-ru.html`, `print-en.html` | исходники печатной вёрстки; создаются `pdf.mjs` локально и в репозиторий не кладутся — по мегабайту на файл, и они полностью выводятся из `pdf.mjs` |
| `build.mjs` | собирает `showcase.html` |
| `pdf.mjs` | собирает оба PDF и печатные исходники |

Скриншоты снимает `../scripts/shots.mjs`.

## Пересобрать

```bash
node scripts/shots.mjs          # снять заново с dev24.pro
node reference/build.mjs        # витрина
node reference/pdf.mjs          # оба PDF
```

`shots.mjs` принимает адрес первым аргументом, если нужно снять со стенда:
`node scripts/shots.mjs http://localhost:4173`.

## Решения, которые стоит знать

**Скриншоты снимаются с `reducedMotion: reduce`.** Иначе кадр ловит анимацию на
полпути: карточки в середине проявления, вращающиеся элементы под углом.

**Масштаб 1 и JPEG качества 74.** Витрина вшивает изображения как data URI,
потому что опубликованная страница не имеет права тянуть файлы с других хостов.
PNG в полном разрешении дали бы многомегабайтный документ.

**Печатная вёрстка — отдельная от веб-витрины.** Это не тёмная страница,
отправленная на принтер: светлый фон, A4, осмысленные разрывы страниц, а
подписи несут то, что на сайте показывают наведение и клик.

**Витрина работает без JavaScript.** Переключатель режимов на обложке собран из
радиокнопок и CSS, поэтому переключается и до загрузки скриптов, и с клавиатуры.
